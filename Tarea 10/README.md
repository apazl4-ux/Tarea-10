Programa desarrollado en C# que utiliza:

-Variables de tipo int, string, bool y decimal.
-Console.WriteLine() para mostrar información y mensajes en pantalla.
-Console.ReadLine() para recibir datos ingresados por el usuario.
-List<Producto> para almacenar los productos del inventario.
-do while para repetir el menú principal.
-switch para ejecutar las opciones seleccionadas por el usuario.
-Métodos para agregar, listar, buscar y guardar productos.
-File.WriteAllLines() y File.ReadLines() para guardar y cargar los productos en un archivo CSV.
-ProductoRepositorio para insertar y listar productos en SQL Server.
-decimal para manejar los precios y calcular el valor total del inventario.

-Abrir el proyecto en Visual Studio Community.
-Presionar F5 para ejecutar el programa.
